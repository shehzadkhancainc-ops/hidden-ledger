Privacy Policy

Last updated: October 15, 2026

This Privacy Policy explains how Hidden Ledger ("we", "us") handles information in connection with our website and our API client, Hidden Ledger Uploader. Hidden Ledger is operated by Shehjadkhan Kalekhan Pathan, Cambridge, Ontario, Canada.

Use of YouTube API Services

Hidden Ledger Uploader uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using Hidden Ledger Uploader, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

Who uses Hidden Ledger Uploader

Hidden Ledger Uploader is a private, single-user tool. It is used only by the owner of the Hidden Ledger YouTube channel to publish the channel's own videos. It is not offered to the public, and no other person can sign in to it.

What information we access

Through YouTube API Services, Hidden Ledger Uploader accesses only the Hidden Ledger channel, signed in with the channel owner's own Google account via OAuth 2.0. It:

  • uploads our own videos and sets their title, description, tags, category, captions and thumbnail;
  • reads our own channel and video details (for example, the channel ID and an upload's processing status);
  • reads our own channel's analytics (views, watch time, average view duration, subscribers gained).

It does not access, collect or store information about any other YouTube user or channel.

What information we store, and where

  • The video ID, link, title and upload time of our own uploads.
  • Analytics figures for our own channel, used to decide which topics to make next.
  • The OAuth access token for our own Google account.

This information is stored only on the channel owner's own computer (or a private server under the owner's control). It is not sold, rented, or shared with any third party.

How long we keep it, and how it is deleted

Stored API data is kept only while it is needed to manage the channel. Analytics data obtained from YouTube API Services is refreshed or deleted at least every 30 days, as required by the YouTube API Services Developer Policies. Video records are deleted when the corresponding video is removed.

Access can be revoked at any time through the Google security settings page. When access is revoked, the stored token stops working and we delete the stored API data within 7 days. You can also ask us to delete any data by emailing the address below.

Visitors to this website

This website is a static information page. It does not use cookies, analytics, advertising trackers or sign-in, and it does not collect personal information from visitors. If you email us, we use your message only to reply to you.

Children

Our website and tools are not directed to children under 13, and we do not knowingly collect information from children.

Changes to this policy

If this policy changes, we will update this page and the "Last updated" date above.
